# Personal Trainer App 💪

A single-page application for a personal trainer to manage customers and training sessions.

Built as the final project of the Frontend Development course at Haaga-Helia University of Applied Sciences.

**Live demo:** https://tanjavatka.github.io/PersonalTrainer

## Features

- **Customers** – list, search, add, edit and delete customers; export the list as CSV
- **Trainings** – list of all training sessions with the customer's name; add and delete trainings
- **Calendar** – trainings in a weekly, monthly and daily calendar view
- **Statistics** – bar chart of total training minutes per activity

## Tech stack

- React + TypeScript
- Vite
- Material UI (MUI Data Grid, Date Pickers)
- React Router
- React Big Calendar
- Recharts
- REST API (provided by the course)
- Deployed with GitHub Pages

## Getting started

```bash
npm install
npm run dev
```
